# Week 3 Sidequest 3: Portal-Inspired Fighting Game

## Setup and Interaction Instructions

**Player 1 Controls:**

- Move: A / D
- Attack: F
- Block: G

**Player 2 Controls:**

- Move: Arrow Keys
- Attack: K
- Block: L

Press **ENTER** to start or rematch.
